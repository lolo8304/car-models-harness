# Vehicle Project Structure Documentation

## Separate Project Structures:
1. **vehicle-api-project/**
   - Mock API service for vehicle catalog and insured-car records
   - GraphQL/Fastify based endpoints
   - JWT authentication via OpenTelemetry API

2. **vehicle-harness-cli**/
   - CLI interface for vehicle search operations
   - Integrated with OpenCode shell commands
   - Mock data and testing framework
